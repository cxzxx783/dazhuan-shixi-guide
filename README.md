## 为什么有这个项目

一个数控专业专科生的亲身经历：翻遍招聘平台、被"大厂实习"忽悠、官网全是硕士本科岗、校招会没好企业……最终发现，专科生找实习的真实路径和网上说的完全不一样。

这个仓库就是把这些**踩坑经验 + 调研成果**整理成可复用的指南，帮后来人少走弯路。

## 核心观点（先记住这三条）

1. **专科生进好企业的通道是"学校校企合作"，不是官网、不是校招会**——官网要本科硕士，好企业走订单班。
2. **"能进"比"含金量"重要**——先选收大专的，再谈好不好。
3. **外包/劳务派遣岗慎碰**——同工不同酬、简历含金量低，签约前问清用工形式。
